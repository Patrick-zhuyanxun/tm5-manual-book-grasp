Manual Book Grasp — TM5-700 安裝與操作手冊

手動四角框選目標書 → ArUco 決定插入方向 → TM5-700 插入書縫夾取。沒有語言查詢與書本辨識。本頁所有指令都假設 repo clone 在 ~/tm5-manual-book-grasp；若放在其他位置，請把每段開頭的 cd 改成實際路徑。

尚未完成 TM5 實機驗收。任何可能移動手臂的操作都要有人在現場、急停可及、TMflow remote/Listen、speed override 5–10%，並先在 RViz 確認當次完整軌跡。異常時立即使用 TMflow Stop 或實體急停，不要依賴 Python 例外或逾時。

0. 系統需求

項目需求
作業系統Ubuntu 22.04，有桌面環境（框選視窗需要 DISPLAY，不建議透過 SSH 操作）
ROSROS 2 Humble（ros-humble-desktop），依官方安裝說明安裝
Python 環境uv（下一節安裝）；不需要 Conda
硬體TM5-700（預設 192.168.1.33）、D435i（USB 3）、夾爪 Arduino（預設 /dev/ttyUSB0）、DICT_4X4_50 ID 0、黑框邊長 50 mm 的 ArUco marker

1. 安裝（每台電腦一次）

1-1. 基本工具與 uv

sudo apt-get update
sudo apt-get install -y git curl
curl -LsSf https://astral.sh/uv/install.sh | sh
export PATH="$HOME/.local/bin:$PATH"
uv --version

1-2. 下載 repo（必須加 --recursive 才會一起下載 TM driver）

cd ~
git clone --recursive https://github.com/Patrick-zhuyanxun/tm5-manual-book-grasp.git
cd ~/tm5-manual-book-grasp

1-3. 一鍵安裝：apt 安裝 MoveIt／Pilz／RealSense 等 ROS 套件、rosdep、uv venv、colcon build。會要求 sudo 密碼，第一次約需 10–20 分鐘。

cd ~/tm5-manual-book-grasp
./scripts/setup.sh
若這台電腦已自行從原始碼安裝 RealSense、MoveIt 等套件（例如原本的 book_grasp_ws 開發機），改用 ./scripts/setup.sh --no-apt 跳過 apt 與 rosdep，並在執行前先 source 提供這些套件的 workspace。

1-4. 夾爪 serial 權限（執行後要登出再登入才生效）

sudo usermod -aG dialout $USER

1-5. 之後每開一個新 terminal 都先執行（ROS → 本 workspace → uv venv，順序固定）：

cd ~/tm5-manual-book-grasp
source scripts/env.sh

不要再 conda activate；Conda 的 Python 或 OpenCV 會蓋掉 venv，導致 cv_bridge 或 ArUco 失效。

2. 安裝驗證（不需要硬體）

cd ~/tm5-manual-book-grasp
source scripts/env.sh
which python3
python3 -c "import numpy, cv2, rclpy, cv_bridge; print('numpy', numpy.__version__, '| opencv', cv2.__version__, '| aruco', hasattr(cv2.aruco, 'estimatePoseSingleMarkers'))"
python3 -m pytest
ros2 pkg executables tm5_manual_book_grasp

預期：

  • which python3 指向 ~/tm5-manual-book-grasp/.venv/bin/python3。
  • numpy 為 1.26.x、opencv 為 4.11.x、aruco 為 True。
  • pytest 全部 passed。
  • executables 列出 manual_book_grasp.py、gripper_node.py 等 5 個程式。

3. 離線規劃檢查（選用，不連手臂）

不給 robot_ip 時只啟動 MoveIt 與 RViz，以固定關節值代替手臂，不會執行任何軌跡。可用來確認模型、碰撞與 RViz 正常。

cd ~/tm5-manual-book-grasp
source scripts/env.sh
ros2 launch tm5_manual_book_grasp tm5-700_with_gripper.launch.py

終端出現 You can start planning now!、RViz 顯示 TM5 + 夾爪 + D435i 即正常。用 Ctrl-C 結束。

4. 每次操作前

  • 確認銘牌是 TM5-700；不得套用 TM12X 教點、TCP、payload 或 hand-eye。
  • 確認工作區無人、急停可及、線材不會勾住；TMflow 無 robot error、e-stop 或 safeguard fault；TMflow 為 remote/Listen，speed override 5–10%。
  • 重新確認 TM5 TCP、payload、重心、D435i hand-eye、碰撞模型、夾爪零點。
  • ArUco ID 0 貼在書架上，從拍攝位置看得到；目標書左右兩側都要完整在畫面內。
ping -c 3 192.168.1.33
lsusb | grep -i intel
ls -l /dev/ttyUSB0

5. Terminal 1 — TM5 driver、模型、MoveIt、RViz

此命令會連接真實 TM5。確認第 4 節完成後才執行。
cd ~/tm5-manual-book-grasp
source scripts/env.sh
ros2 launch tm5_manual_book_grasp tm5-700_with_gripper.launch.py robot_ip:=192.168.1.33

另開 terminal 檢查：

cd ~/tm5-manual-book-grasp
source scripts/env.sh
ros2 topic echo --once /feedback_states
ros2 topic echo --once /joint_states
ros2 action list -t
ros2 run tf2_ros tf2_echo base gripper_tip

確認 feedback、六軸 /joint_states、/move_action、TF 都是新鮮且唯一的。夾爪尚未啟動時 motor 缺少是正常的，不可用 0 猜補。

ros2 launch realsense2_camera rs_launch.py camera_name:=camera camera_namespace:=camera depth_module.depth_profile:=1280x720x30 rgb_camera.color_profile:=1280x720x30 pointcloud.enable:=true align_depth.enable:=true enable_sync:=true clip_distance:=0.8

7. Terminal 3 — 夾爪

cd ~/tm5-manual-book-grasp
source scripts/env.sh
ros2 run tm5_manual_book_grasp gripper_node.py --ros-args -p serial_port:=/dev/ttyUSB0 -p baud_rate:=115200
cd ~/tm5-manual-book-grasp
source scripts/env.sh
ros2 topic info --verbose /gripper/gap
ros2 topic info --verbose /gripper/command

兩者都要有 subscriber，否則 coordinator 會拒絕執行。Arduino 指令只代表「已送出角度命令」，不是力或位置回授。

8. Terminal 4 — 抓取 coordinator

8-1. 乾跑（預設，不會移動）：框選、計算目標、在 RViz 顯示 approach PTP，然後停止。

cd ~/tm5-manual-book-grasp
source scripts/env.sh
ros2 run tm5_manual_book_grasp manual_book_grasp.py --ros-args \
  --params-file install/tm5_manual_book_grasp/share/tm5_manual_book_grasp/config/manual_grasp.yaml

在 RViz 檢查：Manual Grasp Debug 影像中的框與插入點是否在目標書右緣、規劃軌跡是否合理。偵錯圖存在 /tmp/book_grasp_initial.png。

8-2. 完整抓取（會移動手臂與夾爪）

執行前必須完成第 4–7 節，並已用 8-1 確認同一擺設的 RViz 軌跡。motion_enabled:=true 會授權完整序列：移到 stand-off、插入書縫、夾緊、抽出、回到起點。
cd ~/tm5-manual-book-grasp
source scripts/env.sh
ros2 run tm5_manual_book_grasp manual_book_grasp.py --ros-args \
  --params-file install/tm5_manual_book_grasp/share/tm5_manual_book_grasp/config/manual_grasp.yaml \
  -p motion_enabled:=true

執行過程：

  1. 跳出框選視窗 → 框出目標書（見第 9 節）。
  2. RViz 顯示 approach 軌跡 → 終端提示時按 Enter，這是唯一一次移動確認。
  3. 到 70 mm stand-off 後等待 1.5 s，用新畫面驗證，再自動：張開夾爪 → LIN 插入 102 mm → H、T 夾緊 → LIN 向外 232 mm 並上抬 40 mm → PTP 回到起點。
  4. 回到起點時夾爪仍夾著。確認書已被支撐後，再按一次 Enter 才會送 Y、O 釋放。

任一安全閘門（ArUco、TF、深度、MoveIt、碰撞、J5/J6、TCP 路徑）失敗時流程會停止。不要改用其他程式或直接對 TM 發座標。

9. 框選視窗操作

操作按鍵
新增角點（共 4 個，順序不限）滑鼠左鍵
復原上一點滑鼠右鍵 或 Backspace
確認Enter 或 Space
取消（流程中止，不移動）C 或 Esc
  • 只框目標書的書背；右側兩點要精準點在目標書右緣，插入位置就由這條邊決定。
  • 框不可碰到畫面左右邊界，否則會被拒絕。
  • 若畫面有偵測到 ArUco ID 0，視窗中會畫出 marker 外框；沒看到外框代表 marker 不在視野內或角度太斜。
  • 框選逾時 300 秒。只有第一張畫面需要框選，之後的畫面會自動沿用。

10. 停止與故障排查

  1. 正常停止：先在 coordinator 按 Ctrl-C，再依序停止夾爪、相機、Terminal 1。
  2. Ctrl-C 不會鬆開夾爪。夾著書時先確認書已被支撐，再處理夾爪。
  3. 異常運動、碰撞、線材勾住或軟體無回應：立即用 TMflow Stop／實體急停。
  4. 工具可能還在書縫內時，不要直接下斜向回位指令；從 TMflow 沿插入軸退出。
症狀處理
env.sh 顯示 workspace 未建置或 uv 環境不存在重新執行 ./scripts/setup.sh。
No module named cv_bridge、numpy ABI 錯誤、estimatePoseSingleMarkers 不存在確認沒有 activate Conda、which python3 指向 .venv；必要時刪除 .venv 後重跑 setup.sh --no-apt。
Terminal 1 拒絕啟動，訊息提到 lock已有另一個 TM5 MoveIt launch 在執行。先關掉它（ps aux | grep tm5-700_with_gripper）。
框選視窗沒有出現需在本機桌面 terminal 執行，確認 echo $DISPLAY 有值。
夾爪 Permission denied確認已加入 dialout 群組並重新登入；確認 port 名稱（ls /dev/ttyUSB* /dev/ttyACM*）。
找不到 src/tmr_ros2 內容clone 時漏了 --recursive：執行 git submodule update --init --recursive。

source scripts/env.sh
ros2 topic echo --once /feedback_states
ros2 topic list | grep '^/camera/camera/'

11. 更新到新版

cd ~/tm5-manual-book-grasp
git pull
git submodule update --init --recursive
./scripts/setup.sh --no-apt

更新後重新開啟所有 terminal 並 source scripts/env.sh。若新版增加了 apt 相依套件，改跑不帶 --no-apt 的 ./scripts/setup.sh。
